# JAKA Sp. z o.o. (wersja pokazowa)

Statyczny podgląd strony dewelopera domów jednorodzinnych. To tylko pokaz wyglądu.

- Domy, metraże i ceny są przykładowe. Dane firmy i kontakt są prawdziwe.
- Zdjęcia to wizualizacje wygenerowane przez AI, poglądowe.
- Formularz kontaktowy nie wysyła wiadomości, zapisuje je tylko w panelu demonstracyjnym w tej przeglądarce.
- Panel administracji (`/admin/`, login i hasło: `demo`) to symulacja: zmiany zapisują się w przeglądarce odwiedzającego i nie są widoczne dla innych.
- Strona nie jest indeksowana przez wyszukiwarki (`robots.txt`, `noindex`).

Pełna wersja z prawdziwym panelem i bazą danych (PHP) znajduje się w osobnym, prywatnym repozytorium.

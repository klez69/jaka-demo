# JAKA Sp. K. (wersja pokazowa)

Statyczny podgląd strony dewelopera domów jednorodzinnych. To tylko pokaz wyglądu.

- Wszystkie dane (domy, metraże, ceny, adresy, telefon) są przykładowe.
- Zdjęcia to wizualizacje wygenerowane przez AI, poglądowe.
- Formularz kontaktowy nie wysyła wiadomości.
- Strona nie jest indeksowana przez wyszukiwarki (`robots.txt`, `noindex`).

Pełna wersja z panelem administracji i bazą danych (PHP) znajduje się w osobnym, prywatnym repozytorium.
